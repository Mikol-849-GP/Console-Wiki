# Uncharted 2: Among Thieves

**Developer:** Naughty Dog  
**Release Year:** 2009  
**Genre:** Action-adventure

## Overview
Nathan Drake returns in a globe-trotting quest for the lost city of Shambhala. Uncharted 2 blends cinematic storytelling, platforming, and third-person shooting.

## Features
- Seamless transitions between gameplay and cutscenes
- Dynamic environments and set pieces
- Multiplayer modes
- Award-winning voice acting and visuals

## Legacy
A defining PS3 exclusive that set new standards for action games.
